# Data-Analysis-for-House-pricing-dataset
IBM Data Analysis with Python final Project

## Project Overview
In this project, I worked as a data analyst for real estate investment trust. The objective of the project is to analyze housing data and predict house prices using different housing features.

## Problem Statement
The real estate investment trust wants to start investing in residential real estate. The task is to determine the market price of a house using features such as :
- Square footage
- Number of bedrooms
- Number of floors
- Location and other housing attributes
  
## Dataset Information
This dataset contains house sale prices for King Country, which includes Seattle. The dataset includes homes sold between May 2014 and May 2015.
